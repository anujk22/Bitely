# Bitely 🍪

**Your new favorite way to discover delicious recipes from around the world.**

<img width="1728" height="716" alt="bitely" src="https://github.com/user-attachments/assets/099e7355-84da-45c6-8a63-762ca29bdfb1" />

Tired of scrolling through endless recipe blogs just to find out if you have the ingredients? Bitely cuts through the noise. Just search for a meal, and instantly get the full recipe with ingredients, instructions, and a mouth-watering photo—all on one clean card.

## Why Bitely?

🎨 **Beautiful design** – Warm orange gradients and a friendly cookie mascot make finding recipes actually enjoyable

🔍 **Lightning-fast search** – Type any meal name and get results in seconds

📱 **Works everywhere** – Looks gorgeous on your phone, tablet, or desktop

🍳 **No clutter** – Just the recipe. No life stories, no ads, no newsletter popups

## What You'll Find

Every recipe card shows you exactly what you need:
- A clear photo of the dish
- Step-by-step cooking instructions  
- Complete ingredient list with measurements
- Expandable details so you can read as much (or as little) as you want

## Built With

React • Vite • Tailwind CSS • TheMealDB API
